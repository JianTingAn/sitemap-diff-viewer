# Sitemap 差异查看器

比较两个 Sitemap 快照，快速发现新增、删除和地址变化，为百度蜘蛛抓取引导提供可核对的变更记录。

## 核心功能
- 对比两份 URL 清单
- 标记新增、移除和重复地址
- 发现批量改版导致的 URL 波动
- 输出机器可读的差异结果

## 使用
```powershell
python tool.py --demo
python tool.py --input sample.csv --json
```
